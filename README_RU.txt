UMBRELLA TERMINAL 3.0 — ИНСТРУКЦИЯ
================================

УСТАНОВКА
1. Распакуй архив в обычную папку, например Документы.
2. Дважды нажми INSTALL.bat — установятся Pygame и OpenCV в локальную папку .venv.
   Потребуются установленный Python 3 и интернет при первой установке.
3. Программа запускается через START.bat или ярлык Umbrella Terminal на рабочем столе.

ПАРОЛЬ ВХОДА: 9876
Пока вводишь пароль, фоновая музыка НЕ играет.

НАСТОЯЩЕЕ ВЫКЛЮЧЕНИЕ ПК
Сразу после установки включён безопасный DEMO-режим.
Чтобы реально выключать Windows после неправильного ОСНОВНОГО пароля:
1. Войти с кодом 9876.
2. Открыть SECURITY — четвёртая вкладка.
3. Нажать ENABLE (OPT-IN), затем CONFIRM ENABLE.
Теперь ошибка в основном пароле запускает команду выключения Windows через 10 секунд.
В самом приложении кнопки отмены нет. Даже закрытие программы не отменяет
уже запланированное выключение Windows.

КАК ОТМЕНИТЬ ВЫКЛЮЧЕНИЕ (ДО ИСТЕЧЕНИЯ 10 СЕКУНД):
Нажать Win+R, ввести shutdown /a и нажать Enter.
Либо заранее держать рядом файл CANCEL_SHUTDOWN.bat и быстро запустить его.
ПРОВЕРЯЙ ТОЛЬКО ПОСЛЕ СОХРАНЕНИЯ ДРУГИХ ДОКУМЕНТОВ!
Отключить настоящее выключение: SECURITY -> DISABLE.
Либо в settings.json выставить "real_shutdown_enabled": false.

СЕКРЕТНЫЕ ФАЙЛЫ — ШЕСТАЯ ВКЛАДКА
Пять кодов подряд (их можно изменить в settings.json):
1) 1998
2) RACCOON
3) T-VIRUS
4) ALPHA
5) REDQUEEN
Ошибки в этих кодах сбрасывают только прогресс авторизации, ПК не выключается.

Папки досье лежат в secret_files/: Ada Wong, Jill Valentine, Claire Redfield,
Rebecca Chambers и Lady Dimitrescu. Просто положи в нужную папку любую свою
фотографию JPG / PNG / WEBP и сможешь смотреть её в программе. Поддерживаются
и документы; часть форматов открывается через программы Windows.
Вкладка блокируется снова при переходе в другой раздел.
ВНИМАНИЕ: это ТОЛЬКО красивый пароль на интерфейс! Файлы на диске не шифруются.

ЗВОНКИ — ПЯТАЯ ВКЛАДКА
Mamut Rahal и Albert Wesker — это симуляция видеозвонка с портретами.
Твоя вебка включается во время звонка и выключается при его завершении.
Ничего не записывается и не отправляется через интернет.

МУЗЫКА И СИРЕНА
В папку assets/ можно добавить:
- ambience.mp3 — твой ремикс; будет играть только ПОСЛЕ успешного входа.
- siren.mp3 — сирена; играет при неверном ОСНОВНОМ пароле.
Поддерживаются также WAV и OGG. Без сирены будет стандартный электронный сигнал.

ОТДЕЛЬНЫЙ УСТАНОВЩИК .EXE (НЕОБЯЗАТЕЛЬНО)
BUILD_WINDOWS_SETUP.bat создаёт EXE через PyInstaller.
Если установлен Inno Setup 6, создаст классический Setup.exe для Windows.
Сборка такого установщика выполняется на Windows.

ПРОЕКТ ФАНАТСКИЙ. Реальные звонки и шифрование не предусмотрены.
